# PiggyPocket Project Guidelines

## Automatic Git Commit
- After completing any task or work on this repository (adding, modifying, or deleting files), stage and commit the changes automatically:
  ```bash
  git add .
  git commit -m "<human-like, easy-to-understand message>"
  ```
- **Commit Message Style**: Write commit messages that sound natural and human-like (e.g., "Add category filter to expense list", "Fix date picker alignment on mobile", "Update README with setup instructions"). Avoid robotic or overly cryptic jargon.
- **Display Commit**: Always explicitly mention the commit hash and the exact commit message in the response to the user so they can clearly see what was recorded.
